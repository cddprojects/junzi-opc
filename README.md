# 君子小雅OPC

君子小雅OPC研习社（一人公司）课程社区的公开浏览站。移动端对照原小程序信息架构；桌面端是独立的宽屏店面（顶栏导航、多列商品），不再把整站锁在 390px 手机框里。

本站**不接入微信支付、微信登录或原小程序接口**。购买按钮会提示「演示站不支持支付」。

## 本地运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43180](http://127.0.0.1:43180)。

生产构建：

```bash
npm run build
npm start
```

## 管理后台

地址：[http://127.0.0.1:43180/admin](http://127.0.0.1:43180/admin)

- 默认密码：`junzi-admin`（仅供本地演示）
- 正式环境请设置环境变量 `ADMIN_PASSWORD`
- 可增删改：商品/课程、海报轮播、视频
- 支持上传封面图、海报图和视频文件

数据文件：

| 路径 | 说明 |
| --- | --- |
| `data/store.json` | 商品、海报、视频的 JSON 存储（首次访问会用内置种子生成） |
| `data/uploads/` | 上传的图片和视频，通过 `/uploads/文件名` 访问 |

种子文案仍在 [`lib/data.ts`](lib/data.ts)，只在还没有 `store.json` 时写入。之后前台全部读存储，不再只靠硬编码列表。

## 主要页面

| 路径 | 说明 |
| --- | --- |
| `/` | 首页（轮播与课程来自后台数据） |
| `/categories` | 商品分类 |
| `/mine` | 我的（演示登录态） |
| `/product/[slug]` | 课程/商品详情 |
| `/admin` | 管理后台 |

手机上保留底部「首页 / 分类 / 我的」。桌面端使用顶部导航。详情页底部购买条在手机上仍可用。

## 说明

- 未上传视频时，前台继续使用占位封面，不复制原片。
- 购物车只存在当前会话，结算会被演示弹窗拦住。
- 不要把 `ADMIN_PASSWORD` 或上传目录提交到公开仓库。

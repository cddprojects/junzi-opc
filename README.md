# 君子小雅OPC

君子小雅OPC研习社（一人公司）课程社区店的公开浏览站。版式、目录和文案对照原微信小程序截图还原，方便在浏览器里翻看首页、分类、会员与启航营详情。

本站**不接入微信支付、微信登录或原小程序接口**，也不提供课程原片。购买按钮会提示「演示站不支持支付」。

## 本地运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43180](http://127.0.0.1:43180)。桌面端会居中成约 430px 的手机栏，接近小程序窗口。

生产构建：

```bash
npm run build
npm start
```

## 目录从哪里改

课程名称、价格、销量和详情大纲都在 [`lib/data.ts`](lib/data.ts)。改完保存即可，首页、分类和详情页会一起更新。

## 主要页面

| 路径 | 说明 |
| --- | --- |
| `/` | 首页：公告、搜索、轮播、五个分类入口、课程卡片、简介与案例占位 |
| `/categories` | 商品分类：OPC研习社 / 算力加餐 |
| `/mine` | 我的：演示登录态 |
| `/courses/recorded` | 线上录播课 |
| `/courses/live` | 线上直播课 |
| `/workshop` `/events` | 线下工作坊 / 活动报名（9月开启） |
| `/member` | 年度会员（购买为演示弹窗） |
| `/guides` | 操作指南（必看） |
| `/product/qihang` | 启航营详情（高还原） |
| `/product/shizhan` `/product/compute` | 实战营、算力加餐详情 |

底部三个标签在除商品详情外的页面保持：首页 / 分类 / 我的。详情页底部为 首页 / 客服 / 购物车 / 立即购买。

## 说明

- 视频位置使用封面占位，不复制、不抓取原片。
- 购物车仅保存在当前页面会话中，用于演示「+」和结算拦截，刷新后清空。
- 文案为公开店招与课程介绍，不包含学员隐私数据。
